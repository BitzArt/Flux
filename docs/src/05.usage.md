# Usage

## Resolving Flux Set Context

**Set Context** provides access to [operations](02.main-concepts.md#operations) for a configured **Set**.

Inject `IFluxSetContext` into the class that needs to communicate with an external service:

```csharp
public class StudentService(IFluxSetContext<Student> setContext)
{
    // ...
}
```

You can also resolve a **Set Context** from an `IServiceProvider`:

```csharp
var setContext = serviceProvider.GetRequiredService<IFluxSetContext<Student>>();
```

## Basic Usage

Use the resolved **Set Context** to execute operations on the set:

```csharp
var students = await setContext.GetAllAsync();

var studentsPage = await setContext.GetPageAsync(offset: 0, limit: 10);

var student = await setContext.GetAsync(studentId);

await setContext.AddAsync(newStudent);

await setContext.UpdateAsync(updatedStudent, studentId);

await setContext.RemoveAsync(studentId);
```

# Configuration

## Basic Configuration

Basic JSON configuration defines the initial data available through **Set**. Data can be provided as a JSON string or loaded from a JSON file.

### From JSON string

Use `FromJson` when the JSON data is already available as a string.

```csharp
var studentJsonData =
"""
[
    {
        "id": 1,
        "name": "John Doe"
    },
    {
        "id": 2,
        "name": "Jane Doe"
    }
]
""";

services.AddFlux(flux =>
{
    flux.AddService("test-school-api")
        .UsingJson()
        .AddSet<Student>()
            .WithKey(x => x.Id)
            .FromJson(studentJsonData);
});
```

### From JSON file

Use `FromJsonFile` to load the initial data from a JSON file.

```csharp
services.AddFlux(flux =>
{
    flux.AddService("test-school-api")
        .UsingJson()
        .AddSet<Student>()
            .WithKey(x => x.Id)
            .FromJsonFile("data/students.json");
});
```

## Json Serializer Options

Flux.Json uses `System.Text.Json` to serialize and deserialize JSON data.

Use `ConfigureJsonSerializer` to customize `JsonSerializerOptions`:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingJson()
        .ConfigureJsonSerializer((JsonSerializerOptions options) =>
        {
            // Configure options here
        });
});
```

## Configuration

### UsingJson

The UsingJson method configures a Flux service to use JSON as its data source.

This method is typically used during service registration to enable reading 
static data from JSON strings or files—ideal for mock data, testing, or simple data sets.


```csharp
services.AddFlux(flux =>
{
    flux.AddService("service1")
        .UsingJson(baseFilePath: "Data", options =>
        {
            options.PropertyNamingPolicy = JsonNamingPolicy.CamelCase;
        })
        .AddSet<MyModel>()
            .WithKey(x => x.Id)
            .FromJsonFile("sample.json");
});
```

Parameters
* protocolConfigurator: The IFluxServiceProtocolConfigurator used to configure the service.
* baseFilePath (optional): A base directory path used when resolving relative file paths in .FromJsonFile(...).
* configureJsonSerializer (optional): A delegate to customize JsonSerializerOptions for serialization and deserialization.

Returns
* An IFluxJsonServiceBuilder for further set-level configuration.


### WithKey

The WithKey method configures the key property for a JSON-based Flux set. 

This is necessary for Flux to identify individual entities in the set.

Defining the key property allows Flux to perform identity-based operations, such as lookups or updates, when working with data provided via JSON.


```csharp
services.AddFlux(flux =>
{
    flux.AddService("service1")
        .UsingJson()
        .AddSet<MyModel>()
        .WithKey(x => x.Id)         // Define key property
        .FromJson(jsonString);      // Set the data source
});
```

Parameters
* builder: The current builder.
* expression: A lambda expression for configuration.

Returns
* The same instance of Flux Json set builder – IFluxJsonSetBuilder<TModel, TKey>

# Introduction

Flux.Json is a Flux implementation that uses JSON data as its data source.

It is intended for testing purposes. Data can be provided as a JSON string or loaded from a JSON file, allowing your application to use Flux without connecting to an actual external service.

## Installation

Install the Flux Json NuGet package:

```bash
dotnet add package BitzArt.Flux.Json
```

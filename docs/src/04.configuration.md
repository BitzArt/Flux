# Configuration

Flux configuration starts with adding Flux to your application's DI container.

## Add Flux

Use `AddFlux` on your `IServiceCollection` to register Flux.

```csharp
services.AddFlux(flux =>
{
    // Configure Flux here.
});
```

The `flux` parameter gives you access to the Flux builder.

## Add Flux Services

Use `AddService` to register an external system your application communicates with.

```csharp
services.AddFlux(flux =>
{
    flux.AddService("school-api")
        // Configure an implementation package here.
});
```

**Flux Service** must have a unique name. 

`AddService` registers a service. An implementation package then defines how Flux communicates with that external system.

## Advanced Scenarios

### Custom HTTP Message Handlers

**Flux.REST** allows configuring custom [http message handlers](https://learn.microsoft.com/en-us/aspnet/web-api/overview/advanced/http-message-handlers) for your external services. This can be useful for adding custom headers, logging, or any other custom logic.

Example of an http message handler:

```csharp
private class MyHttpHandler : DelegatingHandler
{
    protected override Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        return base.SendAsync(request, cancellationToken);
    }
}
```

To use a custom http message handler, add it when configuring your external service:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("my-service")
        .UsingRest<MyHttpHandler>("http://external.service.address")
});
```

### Using Interceptors

Flux.REST supports interceptors for request and response processing:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("BooksService")
        .UsingRest("https://test.com")
        .WithInterceptor<LoggingInterceptor>() // Add a custom interceptor
        .AddSet<Book>("books");
});
```

Interceptors must implement `IFluxRestInterceptor` and can modify requests before they are sent and responses after they are received.

### Working with Operation Descriptors

For advanced scenarios, you can use operation descriptors directly:

```csharp
// Using operation descriptors for fine-grained control
var descriptor = new GetOperationDescriptor(1, parameters);
var book = await setContext.GetAsync(descriptor);

// Configuring operations inline
var books = await setContext.GetAllAsync(op => 
{
    op.Parameters = parameters;
    // Configure other operation properties as needed
});
```

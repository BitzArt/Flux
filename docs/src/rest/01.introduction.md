# Introduction

This guide shows how to connect your .NET application to a Web API using Flux.REST.

## Installation

Install the [Flux.REST NuGet package](https://www.nuget.org/packages/BitzArt.Flux.Rest):

```bash
dotnet add package BitzArt.Flux.Rest
```

## Get Started

### Example API

The following sections show the school API endpoints and an example JSON representation for each `Course` and `Student` resource.

#### Courses

| Operation | HTTP method | Request URL |
| --- | --- | --- |
| Get Page | `GET` | `https://school-api.example.com/courses?offset={offset}&limit={limit}` |
| Get | `GET` | `https://school-api.example.com/courses/{id}` |
| Add | `POST` | `https://school-api.example.com/courses` |
| Update | `PUT` | `https://school-api.example.com/courses/{id}` |
| Remove | `DELETE` | `https://school-api.example.com/courses/{id}` |

```json
{
  "Id": 1,
  "Title": "Introduction to Biology"
}
```

#### Students

| Operation | HTTP method | Request URL |
| --- | --- | --- |
| Get | `GET` | `https://school-api.example.com/students/{id}` |
| Get Page | `GET` | `https://school-api.example.com/courses/{courseId}/students?offset={offset}&limit={limit}` |

```json
{
  "Id": 1,
  "CourseIds": [1, 2],
  "Name": "Alice"
}
```

A **Set** groups operations for one type of resource. In this example, the course endpoints belong to the Course Set, and the student endpoints belong to the Student Set.

### Configuration

Define C# model classes that match the API's JSON resources:

```csharp
public class Course
{
    public int? Id { get; set; }
    public string? Title { get; set; }
}

public class Student
{
    public int? Id { get; set; }
    public List<int>? CourseIds { get; set; }
    public string? Name { get; set; }
}
```

Register Flux and configure the Course and Student Sets:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("school-api")
        .UsingRest("https://school-api.example.com")
        .AddSet<Course, int>()
            .WithEndpoint("courses")
        .AddSet<Student, int>()
            .WithEndpoint("students")
            .WithGet((PageRequest _) => "courses/{courseId}/students");
});
```

- `AddFlux` registers the Flux Context in the DI container.
- `AddService("school-api")` registers a Flux Service named `school-api` in the DI container.
- `UsingRest` configures the Service to use REST and sets its base URL.
- `AddSet<Course, int>` registers the Course Set in the DI container.
    - `WithEndpoint("courses")` sets `courses` as the endpoint path for all Course Set operations.
- `AddSet<Student, int>` registers the Student Set in the DI container.
    - `WithEndpoint("students")` sets `students` as the endpoint path for all Student Set operations.
    - `WithGet((PageRequest _) => ...)` sets the path for Get Page. It takes precedence over `WithEndpoint("students")` for that operation.

> ℹ️ For advanced endpoint configuration and precedence rules, see [Endpoint Configuration](02.endpoint-configuration.md).

### Resolve Set Contexts

Inject the Set Contexts into the class that uses them:

```csharp
public class SchoolService(
    IFluxSetContext<Course> courseSetContext,
    IFluxSetContext<Student> studentSetContext)
{
}
```

`IFluxSetContext<TModel>` provides operations for a configured Set.

### Work with Sets

#### Courses

Use the injected `courseSetContext` to run Course operations:

```csharp
var coursesPage = await courseSetContext.GetPageAsync(offset: 0, limit: 20);

var course = await courseSetContext.GetAsync(courseId);

await courseSetContext.AddAsync(newCourse);
await courseSetContext.UpdateAsync(updatedCourse, courseId);
await courseSetContext.RemoveAsync(courseId);
```

Flux.REST sends the corresponding HTTP requests shown in the Courses table.

#### Students

The Student Get Page path contains `{courseId}`. Pass its value as a named operation parameter when you call `studentSetContext.GetPageAsync`:

```csharp
var parameters = new OperationParameterCollection(
    new List<KeyValuePair<string, object>>
    {
        new("courseId", 42)
    });

var studentsPage = await studentSetContext.GetPageAsync(
    offset: 0,
    limit: 20,
    parameters: parameters);
```

Flux replaces `{courseId}` with `42`, then appends `offset` and `limit` to the query string. The request URL is:

```text
https://school-api.example.com/courses/42/students?offset=0&limit=20
```

> ℹ️ Pagination configuration is currently in development.

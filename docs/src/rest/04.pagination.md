## Pagination

Flux supports retrieving data in pages. 
This is useful when dealing with large data sets or endpoints that accept pagination parameters.

⚠️ Flux uses the [BitzArt.Pagination](https://github.com/BitzArt/Pagination) library internally for handling paged results. 
You can use its type [Page<T>](https://github.com/BitzArt/Pagination/blob/main/src/BitzArt.Pagination/Models/PageResult/2.PageResult%7BT%7D.cs) for structured paging support in your application.

### Pagination Methods in Flux


#### GetPageAsync(int offset, int limit, params object[]? parameters)

Description:
Fetches a page of items using numeric offset and limit values. This method is used when you want to manually specify how many items to skip and how many to retrieve.

Parameters:
* **offset (int)** – The number of items to skip.
* **limit (int)** – The number of items to retrieve.
* **parameters (object[]?)** – Optional values used to populate path variables in the endpoint (e.g., {authorId}).

Returns:
Task<PageResult<TModel>> – A task that resolves to a PageResult<TModel> containing paged data and optional metadata (such as total count if provided).

Example:

```csharp
var booksPage = await books.GetPageAsync(0, 10, authorId);

// Request → /authors/15/books?offset=0&limit=10
```


##### GetPageAsync(PageRequest pageRequest, params object[]? parameters)

Description:
Fetches a page of items using a PageRequest object instead of raw integers. This overload is useful when you already encapsulate paging info in a PageRequest, often passed from a frontend or API input.

Parameters:
* **pageRequest (PageRequest)** – An object containing Offset and Limit properties.
* **parameters (object[]?)** – Optional values for populating endpoint path variables.

Returns:
**Task<PageResult<TModel>>** – A task that resolves to a PageResult<TModel>.

###### Example:
```csharp
var request = new PageRequest(offset: 0, limit: 10);
var booksPage = await books.GetPageAsync(request, authorId);
```

Related Types
* **PageRequest** – Contains Offset and Limit integers. Used to pass paging arguments as a single object.
* **PageResult<TModel>** – Returned result. Contains paged Items and optional metadata like TotalCount.

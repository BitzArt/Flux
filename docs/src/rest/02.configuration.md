# Configuration

## Basic Configuration

Use `UsingRest` to configure a **Flux Service** with the API's base URL. Then add each **Set** and specify its endpoint path.

```csharp
services.AddFlux(flux =>
{
    flux.AddService("school-api")
        .UsingRest("https://school-api.example.com")
        .AddSet<Student>()
            .WithEndpoint("students");
});
```

The configuration above produces the following requests for Flux operations:

| Operation | HTTP method | Request URL |
| --- | --- | --- |
| Get All | `GET` | `https://school-api.example.com/students` |
| Get Page | `GET` | `https://school-api.example.com/students?offset={offset}&limit={limit}` |
| Get | `GET` | `https://school-api.example.com/students/{id}` |
| Add | `POST` | `https://school-api.example.com/students` |
| Update | `PUT` | `https://school-api.example.com/students/{id}` |
| Update (partial) | `PATCH` | `https://school-api.example.com/students/{id}` |
| Remove | `DELETE` | `https://school-api.example.com/students/{id}` |

## Json Serializer Options

Flux.Rest uses `System.Text.Json` to serialize request bodies and deserialize response bodies.

Use `ConfigureJsonSerializer` to customize `JsonSerializerOptions`:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingRest("https://api.example.com")
        .ConfigureJsonSerializer((JsonSerializerOptions options) =>
        {
            // Configure options here
        });
});
```

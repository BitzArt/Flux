## Error Handling

Flux.REST throws `FluxRestOperationException` when REST operations fail. 
This exception includes the HTTP response message for detailed error information:

```csharp
try
{
    var book = await setContext.GetAsync(1);
}
catch (FluxRestOperationException ex)
{
    // Access the HTTP response for detailed error information
    var statusCode = ex.Response?.StatusCode;
    var responseContent = await ex.Response?.Content?.ReadAsStringAsync();
    
    // Handle the error based on status code
    switch (statusCode)
    {
        case HttpStatusCode.NotFound:
            // Handle not found
            break;
        case HttpStatusCode.Unauthorized:
            // Handle unauthorized
            break;
        default:
            // Handle other errors
            break;
    }
}
```

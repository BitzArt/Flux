## Interceptors

Flux REST interceptors (see IFluxRestInterceptor interface) provide a flexible way to inject custom logic into the lifecycle of HTTP requests and responses in the Flux REST pipeline.

```csharp
services.AddFlux(flux =>
{
    flux.AddService("BooksService")
        .UsingRest("https://test.com")
        .WithInterceptor<LoggingInterceptor>() // Add a custom interceptor
        .AddSet<Book>("books");
});
```

Interceptors can be used for:
* Logging request/response details
* Modifying headers or content
* Implementing retry logic or metrics collection
* Handling error conditions or custom response parsing

Lifecycle and Scope
* Interceptors are resolved via DI using a keyed service (e.g., per service name).
* They are typically registered with ServiceLifetime.Transient, meaning a new instance is created for each 
* request-response cycle.

Customization Points
1.	OnRequestAsync: Triggered before the HTTP request is sent.
1.	OnResponseAsync: Triggered after the HTTP response is received.

To simplify implementation, the FluxRestInterceptor abstract base class provides default no-op methods that can be 
selectively overridden.

# Operation Parameters

Operation parameters provide values for path placeholders and query parameters.

## Named Parameters

Named parameters pair each value with a name. Flux.REST can use that name for a path placeholder or a query parameter:

```csharp
var parameters = new OperationParameterCollection(
    new[]
    {
        new KeyValuePair<string, object>("courseId", 42),
        new KeyValuePair<string, object>("status", "active")
    });

var studentsPage = await studentSetContext.GetPageAsync(
    offset: 0,
    limit: 20,
    parameters: parameters);
```

For the path configured earlier, `courseId` replaces the `{courseId}` placeholder. The `status` parameter is not used by the path, so Flux.REST adds it to the query string. Get Page also adds its non-null `offset` and `limit` values:

```text
https://school-api.example.com/courses/42/students?status=active&offset=0&limit=20
```

Parameter names must match placeholders exactly, including uppercase and lowercase letters. Named parameters must provide a value for every placeholder in the path.

## Automatic Query Parameters

By default, Flux.REST keeps any query string already present in the configured path, then adds unused named parameters and pagination values.

Set the path helper's `queryComplete` argument to `true` when the configured query string is already complete.

For example, suppose the school API expects `skip` and `take` instead of `offset` and `limit`. Build those query parameters from the page request and mark the query as complete:

```csharp
.WithEndpoint((GetPageOperationDescriptor operation) =>
{
    var skip = operation.PageRequest.Offset;
    var take = operation.PageRequest.Limit;
    return $"courses/{{courseId}}/students?skip={skip}&take={take}";
},
queryComplete: true)
```

Calling the Student Get Page operation now produces:

```text
https://school-api.example.com/courses/42/students?skip=0&take=20
```

The resolver reads the requested pagination values and assigns the names expected by the API. Flux still replaces the `courseId` placeholder, but `queryComplete: true` prevents it from also appending the default `offset` and `limit` parameters.

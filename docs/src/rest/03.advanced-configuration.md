## HTTP Client Configuration

Use `ConfigureHttpClient` to configure the `HttpClient` for a **Flux Service**.

```csharp
services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingRest("https://api.example.com")
        .ConfigureHttpClient((HttpClient client) =>
        {
            // Configure the HttpClient here
        });
});
```

Use the overload that provides `IServiceProvider` when the configuration needs a registered dependency:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingRest("https://api.example.com")
        .ConfigureHttpClient((IServiceProvider serviceProvider, HttpClient client) =>
        {
            // Configure the HttpClient here
        })
        // ...
});
```

## HTTP Message Handlers

[HTTP message handlers](https://learn.microsoft.com/en-us/aspnet/web-api/overview/advanced/http-message-handlers) are part of the [`HttpClient` outgoing request middleware](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/http-requests#use-outgoing-request-middleware). You can use a custom `DelegatingHandler` to modify a request before sending it.

```csharp
public class CustomHttpHandler : DelegatingHandler
{
    protected override async Task<HttpResponseMessage> SendAsync(
        HttpRequestMessage request, 
        CancellationToken cancellationToken)
    {
        // Implement custom logic here
        return await base.SendAsync(request, cancellationToken);
    }
}
```

Register the handler in dependency injection, then pass its type to `UsingRest<THandler>`:

```csharp
services.AddScoped<CustomHttpHandler>();

services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingRest<CustomHttpHandler>("https://api.example.com")
        // ...
});
```

## Interceptors

Interceptors run custom logic immediately before an HTTP request is sent and immediately after its response is received. Use them to modify messages, add headers, or record request and response details.

Implement `IFluxRestInterceptor` and provide both callbacks:

```csharp
public sealed class CustomInterceptor : IFluxRestInterceptor
{
    public async Task OnRequestAsync(
        HttpClient client, 
        HttpRequestMessage request, 
        CancellationToken cancellationToken)
    {
        // Implement custom logic here
    }

    public async Task OnResponseAsync(
        HttpClient client, 
        HttpResponseMessage response, 
        CancellationToken cancellationToken)
    {
        // Implement custom logic here
    }
}
```

Register the interceptor for a specific **Flux Service** with `WithInterceptor<TInterceptor>`:

```csharp
services.AddFlux(flux =>
{
    flux.AddService("example-api")
        .UsingRest("https://api.example.com")
        .WithInterceptor<CustomInterceptor>()
        // ...
});
```

The interceptor is registered in dependency injection and can receive registered dependencies from DI. `WithInterceptor<TInterceptor>` uses `ServiceLifetime.Transient` by default and accepts another `ServiceLifetime` when needed.
